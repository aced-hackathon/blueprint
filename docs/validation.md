## 浏览器验收

`tests/browser.cjs` 实际点击四位客户路线、修改现金流、完成清单、撤回权限、保存低碳想法与追问，并在私密沙盒输入独特的虚构 canary。它检查：

- 沙盒静态资源加载完成后，输入与脚本回复产生 **0 个页面网络请求**。
- canary 不在银行侧状态返回、SQLite 文件、任何观察到的请求或浏览器 local/session storage 中。
- 分享请求只包含固定句子 `I am planning to move next month.` 与指定用途。
- 无密钥的回退路径没有外部主机请求；浏览器没有未预期的运行时或 CSP 错误。
- 1440px 桌面及 390px 手机布局不发生水平溢出；离开私密视图后会话清空。

报告和截图保存在被 Git 忽略的 `artifacts/`。网络观察是 Playwright 页面请求事件，覆盖被操作的页面路径；**不是整台机器的抓包，不覆盖系统遥测、扩展或真实本地模型运行时**。服务器发往 OpenAI 的请求不会显示为浏览器对外请求，启用密钥后不能从这个计数判断服务端发送情况。本机没有连接到真实 LLM 账号，因此真实 API 返回质量、可用性和费用待密钥环境实测。零私密对话请求也不能推断真实个人设备本地推理已实现。

## 威胁模型与剩余风险

| 资产 / 风险 | 实现的控制 | 剩余风险 |
| --- | --- | --- |
| 私密草稿被银行流程收集 | 独立沙盒，固定导出 enum，无自由文本入口 | 设备管理员、扩展、恶意浏览器或改动代码仍可读取 |
| 过量模型上下文 | 按用途正向构造允许字段 | 合成汇总仍有语义，不应称为匿名数据 |
| 银行上下文交给远程服务 | 仅启用密钥时调用 OpenAI，结构化最小输入、`store: false`、用户可见请求 | 远程服务仍会处理内容；`store: false` 不表示零保留，真实部署需要核实合同和数据控制 |
| 错误模型提案直接执行 | schema、证据及动作校验，后端政策重新裁决 | 当前仅脚本适配器，真实模型集成需再次验证 |
| 越权客户查询 | 普通 API 从服务端会话取身份 | 高权限 demo selector 有意允许切换，非生产认证 |
| 权限撤回后继续使用 | 同步请求串行化，下一次分析重新计算，无队列或缓存 | 已返回页面的旧内容、已传输信息无法追回 |
| 持久日志泄漏请求 | HTTP 请求日志关闭，不打印 body，不存适配器 capture | 操作系统或外部调试工具日志不在本应用控制内 |
| 泄漏提醒内容 | 通知预览只说有保存任务可继续 | 提醒存在本身仍可透露有互动；没有真实推送 |

没有训练或微调模型；反馈只修改状态、偏好和抑制标记。OpenAI 的通知措辞字段仅作解释候选，实际站内提醒仍由后端固定为不含财务细节的文案。未实施保密计算、同态加密、联邦学习或差分隐私。不比较 Kate 的安全性，也不声称验证了百万用户扩展能力。
